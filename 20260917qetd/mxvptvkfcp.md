# 吞咽困难、进食障碍、反胃烧心……当心贲门失弛缓症！

> 更新时间：2026-09-17 (UTC+8)

//  

近日，我院本部消化内科周春晓主任医师成功为一名贲门失弛缓患者进行了内镜下食管括约肌切开术(POEM术)，  解决了患者一年多来吞咽困难和进食障碍的难题。

**#**

**病例分享**

32岁的俞先生来到我院本部消化内科就诊。周春晓主任询问病情得知，去年开始，俞先生反复出现吞咽困难，伴有明显的反酸烧心感，进食稍多便会胸痛不适，呕吐后症状才有所减轻，夜间更是反酸明显导致咳嗽频繁，整夜难以入眠，体重也因此下降了10多斤。

食管钡剂造影：食管上段扩张

下端黏膜光滑、变细、呈鸟嘴征

周春晓考虑是贲门失弛缓症，进一步复查胃镜、食管吞钡、胸部CT等检查后，证实了他的判断，确诊为**原发性贲门失弛缓症**。

内镜检查：镜下可见贲门口明显狭窄。

周春晓介绍，贲门位于食管和胃的交界，人进食时贲门会打开，让食物进到胃里。但如果食管下段贲门部的神经肌肉功能“失灵”，无法正常收缩，就会导致食管功能障碍，引起贲门失弛缓症。临床常见表现为吞咽困难、胸骨后疼痛、食管反流，以及因食物反流误吸入气管所导致的咳嗽、肺部感染等情况。

术中

结合俞先生病情、药物治疗效果不佳等情况，内镜下食管括约肌切开术是目前的首选手术方式。然而，该手术难度较大，有出血、穿孔、纵膈感染等严重并发症可能，为此周春晓进行了充分的术前准备。在周春晓熟练操作下，手术顺利术后第 3 天，俞先生基本恢复正常饮食，症状消失。
