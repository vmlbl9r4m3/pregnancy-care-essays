# @家长们，百色市人民医院春季幼儿入园体检攻略来啦

> 更新时间：2026-09-11 (UTC+8)

每年的三月份是春季入园的开学时间，许多宝宝到了该上幼儿园的年龄，根据《广西壮族自治区托儿所幼儿园卫生保健管理办法》要求，小朋友入园前需要做一次入园体检，并填写健康检查表，体检合格才能入园。

**百色市人民医院儿童保健科的入园体检常年常规开展，您可以带孩子来医院综合大楼2楼儿童保健科进行入园体检。**

**体检流程**

**入园体检项目**

1. 身高、体重的测量评估

2. 体格检查

3. 视力、听力检查

4. 抽血化验（血红蛋白Hb、丙氨酸氨基转移酶ALT）

**抽血化验可加做项**

1. 乙肝两对半（是否有乙肝抗体）

2. 微量元素测定（检测锌钙铁等元素是否缺乏）

3. 维生素D检测（是否缺乏维生素D）

4. G6PD酶活性检测（是否有蚕豆病）

**注：如果家长需要给小朋友加做以上项目的，请在体检时与开单医生说明。**
